# @genocode/core

The [GenoCode](https://github.com/genocode-org/GenoCode) language: lexer, parser, checker,
formatter and interpreter for `.genie` creature files. It runs in the browser and in Node.

The package also ships the language definition (`@genocode/core/LANGUAGE.md`) and the starter
creatures (`@genocode/core/creatures/*.genie`), for tools that need them.

While the version is 0.x, any minor release may change the API.
