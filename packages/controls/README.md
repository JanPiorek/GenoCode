# @genocode/controls

Controls for trying [GenoCode](https://github.com/genocode-org/GenoCode) creatures in a web page
without editing code: `geneControl` makes a slider, colour picker, checkbox or menu for a gene,
and `InputControls` makes sliders standing in for `time`, `beat` and the `music` values. The
GenoCode app and the VS Code extension's preview both use them.

They're plain DOM elements, styled by the page.

While the version is 0.x, any minor release may change the API.
