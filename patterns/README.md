# Patterns

GenoCode's own pattern kinds, written in GenoCode as pattern files (see
[the language guide, section 14.1](../docs/LANGUAGE.md#141-your-own-patterns)). Each one draws the
same pictures as the built-in kind of the same name, such as `marble`: read them to see how a kind
works, or copy one and change it to make a kind of your own.

The built-in kinds follow the texture generator of Fantastic Avian Creatures (see
[CREDITS.md](../CREDITS.md)).
